KOMPAS-3D MCP подключает КОМПАС-3D к AI-клиентам через MCP. Можно просить Codex, Claude, Roo Code, Cline и другие MCP-клиенты создавать 2D-чертежи, строить 3D-детали, проверять модель, делать скриншоты, экспортировать результат и помогать с диагностикой.

## Что внутри архива

- `kompas-mcp.exe` — готовый MCP-агент для Windows.
- `README.md` — эта инструкция.
- `skills\kompas-mcp-operator` — skill для Codex, чтобы AI лучше понимал рабочие сценарии КОМПАС-3D MCP.
- Служебные runtime-файлы, необходимые для запуска exe.

## Что понадобится

- Windows.
- Установленный КОМПАС-3D на этой же машине.
- MCP-клиент: Codex, Claude Desktop, Roo Code, Cline или другой клиент с поддержкой запуска локальной команды.
- Доступ, полученный через сайт активации.

## Быстрый старт

1. Скачайте последний архив из Releases.
2. Распакуйте его в удобную папку, например:

   ```text
   C:\Programs\kompasmcp
   ```

3. Получите `config.json` на сайте https://kompasmcp.ru. Если нужен invite code, используйте:

   ```text
   invite-d56e976a
   ```

4. Положите `config.json` сюда:

   ```text
   %USERPROFILE%\.kompasmcp\config.json
   ```

5. Подключите exe в вашем MCP-клиенте и перезапустите клиент.

## Подключение в Codex

Codex CLI и расширение читают MCP-настройки из:

```text
%USERPROFILE%\.codex\config.toml
```

Добавьте:

```toml
[mcp_servers.kompas_3d]
command = "C:/Programs/kompasmcp/kompas-mcp.exe"
startup_timeout_sec = 30
tool_timeout_sec = 300
```

Если вы распаковали архив в другую папку, замените путь к exe. После изменения конфига перезапустите Codex или откройте новую сессию. В TUI можно проверить подключение через `/mcp`.

## Подключение в Claude, Roo Code, Cline и похожих клиентах

В MCP-конфиг добавьте сервер с командой запуска exe:

```json
{
  "mcpServers": {
    "kompas-3d": {
      "command": "C:/Programs/kompasmcp/kompas-mcp.exe"
    }
  }
}
```

## Установка skill для Codex

В архиве есть готовый skill:

```text
skills\kompas-mcp-operator
```

Скопируйте папку целиком в:

```text
%USERPROFILE%\.codex\skills\kompas-mcp-operator
```

Skill не обязателен для запуска MCP, но заметно улучшает качество работы Codex: он подсказывает правильные цепочки для 2D, 3D, CAD-as-Code, скриншотов, проверки модели и восстановления после ошибок.

## Что можно делать

- Просить AI построить 2D-чертеж: линии, окружности, дуги, прямоугольники, ломаные, текст, размеры, фаски, скругления, слои и виды.
- Создавать и изменять 3D-детали: новый документ, эскизы на плоскостях и гранях, выдавливания, вырезы, вращение, спирали, sweep/loft-операции, ребра, оболочки, уклоны, массивы, фаски и скругления ребер.
- Проверять модель: активный документ, дерево построения, тела, грани, ребра, свойства, измерения, состояние до/после операции и корректность результата.
- Делать визуальную проверку: переключать 3D-вид, получать скриншоты, проверять изображение по размеру/хэшу и сохранять артефакты.
- Автоматизировать сложные сценарии: CAD-as-Code через `execute_tdcad_script`, геометрические сценарии через `execute_geometry_script`, повторяемые flows через `scenario_runner`.
- Экономить контекст: большие результаты складываются в runtime memory/resources/artifacts, а ответы по умолчанию компактные.

## Как лучше формулировать задачи

Хорошо:

> Создай 3D-деталь: основание 120×80×12 мм, четыре отверстия Ø8 по углам, центральный бобышка Ø30 высотой 20 мм, сделай изометрию и скриншот.

> Открой активный чертеж, добавь прямоугольник, два отверстия, размеры, заполни штамп и экспортируй DXF.

> Проверь, почему вырез появился в дереве, но на модели его не видно; сделай диагностику и предложи исправление.

Лучше указывать размеры, единицы, желаемый документ 2D/3D, путь сохранения и нужен ли скриншот. Если важен внешний вид, просите ортографический и изометрический скриншоты.

## Что важно знать

- КОМПАС-3D должен быть установлен и доступен на Windows-машине, где запускается `kompas-mcp.exe`.
- MCP работает через публичные инструменты и строгие схемы. AI не получает прямой сырой доступ к COM API — команды проходят через безопасный слой агента.
- 3D-ссылки на объекты могут устаревать после перестроения, закрытия, восстановления или смены документа. Хороший клиент будет заново проверять контекст перед следующими операциями.
- Для длинных 3D-цепочек лучше сохранять документ в начале и дальше работать через путь к документу.
- Если операция вернула успех, это еще не всегда означает, что геометрия выглядит правильно. Для серьезных задач используйте проверку дерева, топологии и скриншотов.

## Диагностика, если не запускается

Проверьте, что:

- `kompas-mcp.exe` лежит по тому пути, который указан в MCP-конфиге.
- `config.json` находится в `%USERPROFILE%\.kompasmcp\config.json`.
- КОМПАС-3D установлен на этой Windows-машине.
- После получения `config.json` вы перезапустили MCP-клиент.
- В конфиге используются прямые слэши `/` или корректно экранированные обратные слэши `\\`.
- Антивирус или корпоративная политика не блокируют запуск exe.

Если MCP-клиент видит сервер, но инструменты не работают, откройте КОМПАС-3D вручную и повторите запрос. Для 2D-задач нужен активный чертеж или фрагмент, для 3D-задач — активная деталь или сборка, если задача не создает документ сама.

## Короткий список доступных возможностей

**2D:** документы, виды, слои, линии, окружности, дуги, прямоугольники, точки, ломаные, многоугольники, эллипсы, текст, размеры, фаски, скругления, перемещение, трансформация, удаление, зеркалирование, поиск объектов, измерения, пересечения.

**3D:** документы, свойства детали, базовые сущности, смещенные плоскости, эскизы, операции эскиза, выдавливание, вырез, вращение, sweep/loft, спираль, массивы, оболочка, уклон, ребро жесткости, фаски и скругления ребер, дерево построения, тела, грани, ребра, камера и скриншоты.

**Надежность и автоматизация:** preflight-проверки, snapshot/diff, безопасное создание features, selection helpers, runtime memory, CAD-as-Code, сценарии, компактные ответы, экспорт DXF/JSON и артефакты.
